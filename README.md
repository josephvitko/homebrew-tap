# josephvitko/tap

Homebrew casks for [josephvitko](https://github.com/josephvitko)'s apps.

```sh
brew install --cask josephvitko/tap/powerbar
```

| Cask | |
| --- | --- |
| [`powerbar`](Casks/powerbar.rb) | [PowerBar](https://github.com/josephvitko/powerbar) — menu bar app showing live power draw, per-app energy and battery history |
